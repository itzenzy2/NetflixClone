## 🚀 Quick Start (3 Steps)

### Step 1: Install
```powershell
npm install
```

### Step 2: Configure
Open `.env.local` and add your TMDb API key:
```
NEXT_PUBLIC_TMDB_API_KEY=your_key_here
```

### Step 3: Run
```powershell
npm run dev
```

**Then open**: http://localhost:3000
